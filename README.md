# St. Joseph Catholic Church, Pomona: Lectionary text (Douay-Rheims)

The verses of the Douay-Rheims Bible (Challoner revision) that appear in the Lectionary for Mass,
one small file per chapter, used by the parish website to show the daily and Sunday readings quickly.

* `c/{book}-{chapter}.json` holds `{"verse": "text"}` for the verses the Lectionary uses from that chapter.
  Books are numbered from 0 (Genesis) in the order of the source file.
* Text: Douay-Rheims Bible, Challoner revision, **public domain**, taken unchanged from
  [scrollmapper/bible_databases](https://github.com/scrollmapper/bible_databases) at commit
  `e1b254cef86d0e65b1a5d1a94b8b112d0f296a2c` (`formats/json/DRC.json`).
* Reading citations follow the Lectionary for Mass for use in the dioceses of the United States.
  The NABRE translation read at Mass is copyrighted and is **not** included here.
